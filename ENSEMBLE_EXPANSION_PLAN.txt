OPTION 3: STACKED GENERALIZATION (Level 2 + Level 3)
Purpose: Two-level meta-learning

Level 2: Combine base models with Ridge
Level 3: Second meta-learner on Level 2 predictions + original features

Implementation:
  # Level 1: 12 base models
  base_preds = [model.predict(X) for model in base_models]
  
  # Level 2: Ridge combination
  level2_input = np.column_stack(base_preds)
  level2_model = Ridge(alpha=1.0)
  level2_model.fit(level2_input, y_train)
  level2_pred = level2_model.predict(level2_input)
  
  # Level 3: Meta-meta-learner with original features
  level3_input = np.column_stack([level2_pred, X_train])
  level3_model = lgb.LGBMRegressor(n_estimators=200, max_depth=4)
  level3_model.fit(level3_input, y_train)

Benefits:
  - Deeper hierarchy captures more complex patterns
  - Level 3 can use original features to correct Level 2 errors
  - Maximum ensemble power


OPTION 4: WEIGHTED VOTING WITH LEARNED WEIGHTS
Purpose: Learn optimal weights for each base model

Implementation:
  from scipy.optimize import minimize
  
  def weighted_ensemble_loss(weights):
      weights = weights / np.sum(weights)  # Normalize
      ensemble_pred = sum(w * pred for w, pred in zip(weights, base_preds))
      return np.sqrt(mean_squared_error(y_val, ensemble_pred))
  
  # Optimize weights
  initial_weights = np.ones(n_models) / n_models
  result = minimize(weighted_ensemble_loss, initial_weights, 
                    method='SLSQP', 
                    bounds=[(0, 1)] * n_models)
  
  optimal_weights = result.x / np.sum(result.x)

Benefits:
  - Simple and interpretable
  - Can identify which models are most valuable
  - No risk of overfitting (linear combination)

TECHNIQUE 1: CASCADED RESIDUAL MODELS
Train Multiple Residual Models in Sequence:

  # Residual Stage 1: Correct large errors
  residuals_1 = y_train - ensemble_pred
  residual_model_1 = lgb.LGBMRegressor(
      n_estimators=300, max_depth=8, learning_rate=0.03
  )
  residual_model_1.fit(X_train, residuals_1)
  residual_pred_1 = residual_model_1.predict(X_train)
  
  # Residual Stage 2: Correct remaining errors
  residuals_2 = residuals_1 - residual_pred_1
  residual_model_2 = lgb.LGBMRegressor(
      n_estimators=200, max_depth=6, learning_rate=0.02
  )
  residual_model_2.fit(X_train, residuals_2)
  residual_pred_2 = residual_model_2.predict(X_train)
  
  # Final prediction
  final_pred = ensemble_pred + residual_pred_1 + residual_pred_2

Benefits:
  - Each stage corrects different error patterns
  - Progressive refinement
  - Inspired by boosting cascade

  # Train ensemble to predict both mean and variance

  # Weight residual corrections inversely by uncertainty

  corrected_pred = ensemble_pred + residual_weight * residual_pred

Benefits:
