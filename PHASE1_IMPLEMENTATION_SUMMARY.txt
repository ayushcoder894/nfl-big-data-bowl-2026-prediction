C. TRAINING PIPELINE
--------------------
Each model is trained using 3-fold GroupKFold cross-validation:

For X-coordinate:
  1. Split data into 3 folds (grouped by game_id to prevent leakage)
  2. For each fold:
     - Train on 2 folds, validate on 1
     - Store out-of-fold predictions
  3. Average validation predictions across folds
  4. Train final model on all training data

For Y-coordinate:
  (Same process as X-coordinate)

Meta-learning:
  1. Stack all 10 models' out-of-fold predictions
  2. Train Ridge regression meta-learner
  3. Compare with simple averaging
  4. Use whichever performs better

Residual refinement:
  1. Compute residuals from meta-learner
  2. Train gradient boosting on residuals
  3. Add residual predictions to final output
